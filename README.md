# Employee Document & Renewal Management Portal

A web-based employee document management portal built with Google Apps Script, Google Sheets, and Google Drive.

## Features

- Employee login and password management
- Role-based access for employees and HR
- Employee document upload and retrieval
- Document expiry tracking
- HR dashboard for employee and document management
- Server-side authorization checks

## Technology Stack

- Google Apps Script
- JavaScript
- HTML and CSS
- Google Sheets
- Google Drive

## How It Works

Google Apps Script handles application logic and authorization. Google Sheets stores employee and document metadata, while Google Drive stores uploaded files.

## Security

The application uses server-side access checks to restrict access to employee records and documents.

**Portfolio note:** This repository must contain only authorized, sanitized source code and synthetic demo data. Never publish real employee records, company credentials, private file IDs, or confidential information.
